Settings

Your name
Let Mist know what to call you. Leave this blank and Mist won't try to use a name at all.
Background animation
Show the drifting mist behind the main screen. Turning this off can help on slower devices.
Auto-scroll while generating
Automatically follow the response while Mist is generating it.
Send message with Enter
When on, Enter sends your message (Shift+Enter for a new line). When off, Enter always starts a new line and you send with the button instead.
Show timestamps
Show when each message was sent, underneath it.
Instant responses
Skip the typing animation and show each response all at once, as soon as it's ready.
Remember past chats
Let Mist bring in brief, relevant context from your other chats on this device that haven't been deleted — so it doesn't start from zero every time.
Voice
Used when reading Mist's responses aloud. Mist picks the closest-sounding voice available on your system by default.
Read responses aloud automatically
Speak each reply out loud as soon as it finishes.
Speaking rate
How quickly Mist speaks when reading aloud.
Speaking pitch
Lower is deeper and calmer, higher is brighter.
Export your chats
Download every chat on this device as a single JSON file.
Clear all chats
Permanently delete every chat on this device. This cannot be undone.
